# Contributing

## Setup

1. Install Elixir/OTP and Rust toolchain.
2. Run `make setup`.
3. Run `make test`.

## Pull requests

- Keep PRs focused and small.
- Add/update tests for behavior changes.
- Ensure `make lint` and `make test` pass.

## Commit style

- Use clear, imperative commit messages.
- Explain why in the PR description.
